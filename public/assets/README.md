# Wedding media placeholders

Replace these zero-byte placeholders with the supplied media files using the same filenames. They intentionally contain no fabricated photos or audio; images fall back to a paper placeholder until replaced.

- `couple-main.jpg`
- `couple-1.jpg` through `couple-6.jpg`
- `bride.jpg`
- `groom.jpg`
- `background-music.mp3`

Until supplied, image frames display a warm paper placeholder and the music control remains silent. The website references these paths directly.
